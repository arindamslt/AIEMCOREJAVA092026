SYNCHRONIZATION
=================================================================
IT IS A SITUATION WHEN ONE THREAD ACCESSING THE SHARED RESOURCE
OTHER THREADS UNABLE TO ACCESS IT.
DURING THE SYNCHRONIZATION ONE LOCK HAS BEEN APPILED CALLED MUTEX I.E. MUTUALLY
EXCLUSIVE LOCK
THIS SITUATION IS CALLED CRITICAL SECTION
DEADLOCK
=================================================================
WHEN ONE THREAD ACCESSING ONE SHARED RESOURCE AND OTHE THREAD ALREADY ACCESS
ANOTHER SHARED RESOURCE.
AT PRESENT FIRST THREAD WANT TO ACCESS THE SHARED RESOURCE HOLD BY SECOND THREAD
AND VICE VERSA.THESE SITUATION IS CALLED DEADLOCK
